# FAQ

**Frage:** Es steht „Kein Widget gewählt“.

Antwort: Im Block ist noch kein Widget eingestellt. Im Studio den Dialog des
Blocks öffnen und unter **Widget wählen** eines aussuchen.

**Frage:** Es steht, das Widget sei in dieser Umgebung nicht installiert.

Antwort: Der Block zeigt nur Widgets, die in dieser Staffbase-Umgebung
registriert sind. Ist es woanders installiert (etwa nur auf truck, nicht auf
van), bleibt der Block hier leer.

**Frage:** Es steht „Für dieses Widget gibt es noch keine Dokumentation.“

Antwort: Das Widget liefert (noch) keine Doku mit. Sie kommt mit einem
späteren Release.

**Frage:** Das Kapitel „Änderungen“ fehlt.

Antwort: Die Liste der Änderungen entsteht beim Release. Widgets, die seit
der Umstellung noch keinen Release hatten, zeigen das Kapitel erst danach.

**Frage:** Kann ich die Texte hier bearbeiten oder eigene Hinweise ergänzen?

Antwort: Nicht in diesem Block. Die Texte gehören zum Widget und kommen mit
dessen Release. Eigene Hinweise gehören in einen eigenen Abschnitt der Seite.

**Frage:** Warum sehe ich die Doku auf Deutsch, obwohl meine Sprache eine
andere ist?

Antwort: Das Widget bringt für Ihre Sprache keine Übersetzung mit. Dann
erscheint die deutsche Fassung.
