# Configuración

Este widget **no tiene configuración**. Basta con colocarlo en una página;
el contenido y la navegación se derivan íntegramente de los
widgets instalados.

## Lo que sí puedes configurar

| Punto | Descripción |
| --- | --- |
| Público objetivo | Viene determinado por la página, no por el widget. Lo más adecuado es una página para redactores y redactoras. |
| Ubicación | Lo mejor es que ocupe todo el ancho de la página. La barra lateral y el contenido necesitan espacio. |
| Alcance | No se puede controlar: siempre aparecen todos los widgets instalados que incluyan documentación. |
