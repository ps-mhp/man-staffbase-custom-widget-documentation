# Configuración

| Configuración | Descripción |
| --- | --- |
| **Widget** | Campo obligatorio. El widget cuya documentación muestra el bloque. Se pueden seleccionar todos los widgets instalados en este entorno; los widgets sin documentación aparecen marcados. |

El resto depende del widget seleccionado:

| Elemento | Procedencia |
| --- | --- |
| Capítulo | De la documentación del widget, en el orden que figura en ella, además de **modificaciones**. |
| Versión | La última versión del widget. No se puede seleccionar una versión anterior. |
| Idioma | El idioma de los lectores; en caso contrario, alemán. |
| Público objetivo | De la página, no del widget. |
