# FAQ

**Question :** Un widget manque dans la liste.

Réponse : Seuls les widgets installés dans cet environnement
**et** accompagnés d’une documentation sont répertoriés. Les versions récemment publiées
nécessitent en outre un peu de temps avant que la documentation ne soit disponible via le réseau de distribution.
Veuillez recharger la page ultérieurement.

**Question :** Le message « Recherche des widgets… » s'affiche et rien ne se passe.

Réponse : La liste des widgets installés est en cours de chargement. Si ce message
persiste, cela est généralement dû à une connexion Internet instable ou à un bloqueur dans le navigateur ;
actualisez la page et réessayez.

**Question :** Le message « Cette page n’a pas pu être chargée » ou
« La documentation de la version X n’a pas pu être chargée » s’affiche.

Réponse : La documentation n’est pas disponible pour cette version précise — il s’agit généralement d’une
version très récente ou très ancienne. Réessayer plus tard permet généralement de
résoudre le problème ; sinon, sélectionnez une autre page via la liste des widgets.

**Question :** Un message en haut de la page indique que je ne vois pas la version la plus récente.

Réponse : La version installée est plus ancienne que la dernière disponible. Le
bouton **Passer à la version actuelle** affiche la documentation la plus récente —
attention : elle peut décrire des fonctionnalités qui ne sont pas encore disponibles dans votre version
installée.

**Question :** La recherche ne donne aucun résultat.

Réponse : La recherche porte sur les titres de page et le corps du texte des
documentations chargées ; un champ de recherche vide ne donne aucun résultat, et
seuls dix résultats au maximum sont affichés. Effectuez une nouvelle recherche
avec un terme plus court et plus général.

**Question :** Un exemple indique : « Aucun
ensemble de données réel n’est actuellement disponible pour cet exemple. »

Réponse : Ce n’est pas une erreur. Aucun exemple concret n’a pu être chargé pour ce widget
— peut-être parce qu’il n’existe pas de contenu adapté ou que celui-ci n’est pas
visible pour vous. Ce sont donc les valeurs d’exemple qui s’affichent à la place.

**Question :** Puis-je modifier les textes ici ou ajouter mes propres remarques ?

Réponse : Pas sur cette page. Les textes appartiennent au widget concerné et
sont fournis avec sa version. Vos propres ajouts doivent figurer sur une page distincte
ou dans un élément de texte à côté de ce widget.

**Question :** Dans quelle langue la documentation s'affiche-t-elle ?

Réponse : Dans la langue fournie par le widget concerné avec sa version.
Si une version linguistique fait défaut, c'est celle qui est disponible qui s'affiche.
