# FAQ

**Question :** Le message « Aucun widget sélectionné » s'affiche.

Réponse : Aucun widget n'est encore configuré dans le bloc. Dans Studio, ouvrez la boîte de dialogue du
bloc et sélectionnez-en un sous **Sélectionner un widget**.

**Question :** Un message indique que le widget n’est pas installé dans cet environnement.

Réponse : Le bloc n’affiche que les widgets enregistrés dans cet environnement Staffbase.
S’il est installé ailleurs (par exemple uniquement sur « truck », et non sur
« van »), le bloc reste vide ici.

**Question :** Le message « Il n’existe pas encore de documentation pour ce widget » s’affiche.

Réponse : Le widget ne fournit pas (encore) de documentation. Celle-ci sera disponible lors d’une
prochaine version.

**Question :** La rubrique « Modifications » est manquante.

Réponse : La liste des modifications est générée lors de la mise à jour. Les widgets qui n’ont pas encore
fait l’objet d’une mise à jour depuis la migration n’afficheront ce chapitre qu’après celle-ci.

**Question :** Puis-je modifier les textes ici ou ajouter mes propres remarques ?

Réponse : Pas dans ce bloc. Les textes font partie du widget et sont fournis avec
sa mise à jour. Vos propres remarques doivent figurer dans une section distincte de la page.

**Question :** Pourquoi la documentation s'affiche-t-elle en allemand alors que ma langue est
une autre ?

Réponse : Le widget ne propose pas de traduction dans votre langue. C'est pourquoi
la version allemande s'affiche.
