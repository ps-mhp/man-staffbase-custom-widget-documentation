# FAQ

**Question:** It says “No widget selected.”

Answer: No widget has been set up in the block yet. In Studio, open the block’s
dialog box and select one under **Select Widget**.

**Question:** It says the widget isn’t installed in this environment.

Answer: The block only displays widgets that are registered in this Staffbase
environment. If it’s installed elsewhere (for example, only on “truck,” not on
“van”), the block will remain empty here.

**Question:** It says, “There is no documentation for this widget yet.”

Answer: The widget does not (yet) include documentation. It will be included in a
later release.

**Question:** The “Changes” section is missing.

Answer: The list of changes is generated upon release. Widgets that haven’t had a
release since the migration won’t display this section until after a release.

**Question:** Can I edit the text here or add my own notes?

Answer: Not in this block. The text is part of the widget and comes with
its release. Your own notes should go in a separate section of the page.

**Question:** Why do I see the documentation in German even though my language is
different?

Answer: The widget does not include a translation for your language. In that case,
the German version appears.
