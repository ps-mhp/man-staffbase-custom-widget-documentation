# FAQ

**Question:** A widget is missing from the list.

Answer: Only widgets that are installed in this environment
**and** include documentation are listed. Newly released versions
also take a moment for the documentation to become available via the distribution network.
Please reload later.

**Question:** It says “Searching for widgets…” and nothing happens.

Answer: The list of installed widgets is currently loading. If it
stays that way indefinitely, it’s usually due to a network issue or a browser blocker;
refresh the page and try again.

**Question:** The message “This page could not be loaded” or
“Documentation for version X could not be loaded” appears.

Answer: The documentation for this exact version is not available—usually a
very new or very old version. Trying again later usually helps;
otherwise, select a different page from the widget list.

**Question:** It says at the top that I’m not seeing the latest version.

Answer: The installed version is older than the latest available one. The
**Switch to Current Version** button displays the newer documentation—
Note: It may describe features that are not yet available in your installed version.

**Question:** The search isn’t finding anything.

Answer: The search looks in page titles and the body text of the loaded
documentation; an empty search field returns no results, and
at most ten results are displayed. Try searching again with a shorter, more general term
.

**Question:** An example says, “No
live data set is currently available for this example.”

Answer: This is not an error. No real example could be loaded for this widget at the moment
— perhaps because there is no suitable content or because it is not
visible to you. Instead, the example values are displayed.

**Question:** Can I edit the text here or add my own notes?

Answer: Not on this page. The text belongs to the respective widget and
is included with its version. Your own additions should go on a separate page
or in a text element next to this widget.

**Question:** In which language is the documentation displayed?

Answer: In the language that the respective widget provides
with its version. If a language version is missing, the available one is displayed.
